# 💱Currency Converter

## Descrição

Este projeto é um simples conversor de moedas simples desenvolvido com HTML, CSS e JavaScript. Ele permite aos usuários converter valores entre diferentes moedas utilizando taxas de câmbio atualizadas.


## 🚀 Funcionalidades

- Conversão entre múltiplas moedas (USD, EUR, BRL, etc.)
- Interface amigável e responsiva
- Exibição automática da taxa de câmbio atual

## Pré-requisitos

- Navegador moderno (Chrome, Firefox, Safari, Edge)

- Conexão com a internet para obter as taxas de câmbio via API (opcional)

## 🛠️ Tecnologias Utilizadas

- HTML5
- CSS3
- JavaScript 

Estrutura de Pastas
````
conversor-moedas/
├── assets
├── index.html       # Arquivo principal HTML
├── styles.css       # Estilos CSS
├── script.js        # Lógica JavaScript
└── README.md        # Documentação do projeto
````
